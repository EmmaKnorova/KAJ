How to write notes 🎵:

  • Note and octave: Enter a letter (C-B) and an octave (1 or 2).
    Example: C1, G2
  • Length: Add the duration in parentheses:
    (4) = whole note
    (2) = half note
    (1) = quarter note
  • Separate multiple notes with a space.
    Example: C1(4) E1(4) G1(2)
